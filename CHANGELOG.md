# Release Notes

## [Unreleased](https://github.com/aldo-octavio-cahyadi/avian-ui/compare/v0.1.0...1.x)

- Add the `datalist` component (+ `datalist.item`): a paginated collection shown as a list or a grid of cards, with a view toggle, `persist`, `wire:model` support and the table's empty state.
- Add the `multi-select` component (+ `multi-select.option`) for picking several values with search and chips.
- Render an empty state in `table` when it has no rows, configurable through `empty`, `empty-text`, `empty-icon`, `columns` and an `empty` slot.
- Position the `dropdown` menu with fixed coordinates so scrolling containers such as tables no longer clip it.
